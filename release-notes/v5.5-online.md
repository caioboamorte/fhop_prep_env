## Português

Versão **v5.5 Online**, revisada e testada por Caio, para preparar Ubuntu 22.04/24.04 amd64 usando a Internet.

### Principais recursos

- Executa apenas com `fh2-onprem-prep-tool-v5.5-online.sh`, sem `docker.tar.gz` ou bundles locais.
- Baixa Docker Engine/CLI **27.2.0**, Compose **2.29.2**, containerd **1.7.21** e Buildx **0.16.2** pelo repositório oficial.
- Protege o Docker existente antes da atualização do Ubuntu.
- Baixa os cinco pacotes Docker antes de liberar bloqueios ou remover pacotes conflitantes.
- Solicita confirmação antes de alterar uma instalação Docker existente.
- Valida Engine, Compose e containerd e aplica `apt-mark hold` aos pacotes Docker.
- Baixa dependências, Chrome e driver NVIDIA recomendado quando necessário.
- Mantém `--check-only` e `--reboot`.
- Inclui documentação em português e inglês comparando as versões online e com bundle.

### Como usar

```bash
curl -fL --retry 3 \
  https://raw.githubusercontent.com/caioboamorte/fhop_prep_env/v5.5-online/fh2-onprem-prep-tool-v5.5-online.sh \
  -o fh2-onprem-prep-tool-v5.5-online.sh

sudo bash fh2-onprem-prep-tool-v5.5-online.sh --check-only
sudo bash fh2-onprem-prep-tool-v5.5-online.sh
```

O servidor precisa acessar as fontes de pacotes Ubuntu, Docker e Google. A variante online não aceita `--offline`. Para servidores sem Internet, use o bundle da [release v5.5](https://github.com/caioboamorte/fhop_prep_env/releases/tag/v5.5).

### Validação

Revisão e testes confirmados por Caio em 09/10/2026. Também passaram as verificações de sintaxe Bash, ajuda e seleção exata de versões com dados simulados.

## English

**v5.5 Online**, reviewed and tested by Caio, prepares Ubuntu 22.04/24.04 amd64 using Internet downloads.

- Runs from a single `.sh` file, without `docker.tar.gz` or local bundles.
- Downloads Docker Engine/CLI **27.2.0**, Compose **2.29.2**, containerd **1.7.21**, and Buildx **0.16.2** from the official repository.
- Protects existing Docker packages before Ubuntu updates.
- Downloads all five Docker packages before unlocking or removing conflicting packages.
- Requires confirmation before modifying an existing Docker installation.
- Validates Engine, Compose and containerd and applies APT package holds.
- Downloads dependencies, Chrome and the recommended NVIDIA driver when needed.
- Supports `--check-only` and `--reboot`.
- Includes bilingual documentation comparing online and bundle workflows.

Use the commands above. The server must reach Ubuntu, Docker and Google package sources. For offline servers, use the [v5.5 bundle release](https://github.com/caioboamorte/fhop_prep_env/releases/tag/v5.5).

Caio confirmed review and testing on 2026-10-09. Bash syntax, help and simulated exact-version selection checks also passed.
